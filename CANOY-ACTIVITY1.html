Lesson 1: How Webpages Work

Understanding how websites are created and displayed.

How Webpages Work

A webpage is a document that is displayed through a web browser. Webpages are mainly created using HTML, styled with CSS, and can use JavaScript to add interactive features.

HTML

HTML stands for HyperText Markup Language. It provides the structure and content of a webpage.

CSS

CSS stands for Cascading Style Sheets. It controls the appearance, layout, colors, fonts, and overall design of a webpage.

Web Browser

A web browser reads HTML, CSS, and other web files and displays them as a webpage that users can interact with.
