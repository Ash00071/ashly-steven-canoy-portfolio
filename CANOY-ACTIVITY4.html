Lesson 4: Forms and Semantic HTML

Learning how to create forms and organize webpages using semantic HTML.

HTML Forms

HTML forms allow users to enter and submit information on a webpage.










Semantic HTML

Semantic HTML uses meaningful elements that describe the purpose of different parts of a webpage.

  • <header> - contains introductory content
  • <nav> - contains navigation links
  • <main> - contains the main content
  • <section> - groups related content
  • <footer> - contains footer information
